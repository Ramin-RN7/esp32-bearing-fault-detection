# Audio-Based Bearing Fault Detection (Supplementary Materials)

This repository contains the supplementary materials for the Master's thesis:

"Audio-Based Bearing Fault Detection on Resource-Constrained Microcontrollers: An Ablation-Driven Study"

## Structure

01_uottawa_wavs/ — dataset (converted WAV files)
02_data_segmentation/ — segmentation scripts
03_feature_extraction/ — feature pipelines
04_model_training_ablation/ — ablation experiments
05_model_export/ — export scripts + final models
06_results_evaluation/ — summary results
07_confusion_matrices_full/ — full confusion matrices

## Dataset

Original dataset:
https://data.mendeley.com/datasets/y2px5tg92h/5

## Notes

- Code is designed for reproducibility of the ablation study
- Minor adjustments may be required for new datasets (paths, labels)
