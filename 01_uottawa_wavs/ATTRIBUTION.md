# Dataset attribution

These WAV files are derived from the **University of Ottawa bearing vibration/acoustic dataset (UORED-VAFCLS), version 5**, created by **Mert Sehri and Patrick Dumond**, published on 13 October 2023.

- Dataset: https://data.mendeley.com/datasets/y2px5tg92h/5
- DOI: https://doi.org/10.17632/y2px5tg92h.5
- License: **Creative Commons Attribution 4.0 International (CC BY 4.0)**
- License terms: https://creativecommons.org/licenses/by/4.0/

The original microphone data were converted to WAV for the thesis workflow. The included recordings are 16 kHz WAV files; the source dataset describes acquisition at 42 kHz. This conversion is a modification of the original data. The dataset creators have not endorsed this thesis or repository.

The dataset license is separate from the licensing of the authored code and thesis documents.
